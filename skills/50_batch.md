# 50 批量 / 参数化仿真（先谈框架，再问范围）

**触发**：用户想"批量跑 / 参数扫描 / 敏感性分析 / 全自动仿真"。

## 第 1 步：与用户协商【框架】（`set_batch_plan`）
**先谈清楚，再动手**。逐项与用户确认并记录：
1. **基准模型**：以哪个已跑通的模型为底（哪些部件、什么工况）；
2. **扫描变量（自变量）**：要变哪几个参数（如 加热功率、入口流量、管径、面积比…）；
3. **观察量（因变量）**：要汇总看什么（出口温度、压降、流量分配、最大空泡…）；
4. **工况类型**：稳态 / 瞬态。
**框架没谈拢，不许开跑。**

## 第 2 步：向用户询问【参数范围】
对上一步每个扫描变量，用 `ask_user` **逐项**问清：**取值范围 + 步长/取值点**（给建议范围与默认值）；
确认后 `remember_requirement` 落账、更新 `set_batch_plan`。
- **不臆造范围**；用户说"你定"时采用显式默认并在报告注明"此为默认，可改"。
- **控制工况数**：笛卡尔积别爆（超 20 个要提醒用户收窄，或显式同意）。

## 第 3 步：做参数化模板（`write_file`）
- 先有一个**已真跑通过**的基准 `.i`；把要扫的量替换成占位符 `{{参数名}}`（如 `{{power}}`）；
- `validate_i` 静态检查；并**单跑一次**确认模板本身没问题（占位替换后仍能跑）。

## 第 4 步：批量真跑（`batch_sim`）
- `batch_sim(template, vary)`：vary = `[{"name":"power","values":[1e5,2e5,3e5]}, ...]`；
- 工具自动做：笛卡尔积 → 逐个渲染 → 真跑 → **守恒/量级校验** → 汇总成表 + 写 CSV；
- 汇总含每工况 **voidg_max（最大空泡份额，烧干判据）与 烧干?**、温度范围；CSV 的 `o` 列是各工况
  `.o` 路径，需要深看某工况就用 `result_summary`/`transient_history` 读它（**不要** python_exec 翻）；
- 单工况超时/失败会记录（含首条错误），不中断整批。

## 第 5 步：报告
- 给**汇总表**与**趋势/规律**（如"功率↑→出口温度↑，ΔT 与 Q/(m·cp) 线性"）；
- **必须点出异常工况**（未正常结束 / 质量误差大 / 温度越界）并说明可能原因；
- 产物：CSV + 各工况 `.i` 在 `workspace/batch/`；有价值的基准/代表样例可 `save_example`。

> 原则同前：**每个工况都要物理自洽**，异常不得忽略；**范围与框架先与人谈定**，不替用户拍板。
