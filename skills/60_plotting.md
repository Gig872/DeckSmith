# 60 用图讲结果（读图解读）

**触发**：要**汇报/解释**运行结果，尤其用户问「趋势怎样」「为什么」「安不安全」「会不会烧干/壅塞」；
或批量扫描要看**规律/拐点/阈值**。

## 铁律：先拿数，再讲图
**不要凭印象形容曲线**。讲任何一条趋势前，先用工具把**数值特征**拿到手：
- `plot_series(o_path, var, thr?)` —— 出图（界面自动弹「结果图」窗口）+ 返回**曲线特征**；
  **报告结果优先用它**（一箭双雕：用户看到图，你拿到数）。
- `curve_features(o_path, var, thr?)` —— 只要特征、不出图（省事时用）。
- `extract_series(o_path, var)` / `result_summary` —— 要看**具体读数表**时用。
- `scan_series(summary_csv, x_col, var)` —— **批量趋势**（参数→结果）用；配套窗口「批量扫描趋势图」。

## 读图三步
1. **定坐标**：x 是时间(s)还是参数？y 是哪个变量、什么单位？（别把声速当温度——列序随工况变，**只用工具读数**）
2. **抓特征**：从返回的特征里挑出**峰/谷(值@时刻) · 末端平台 · 阈值穿越 · 振荡 · 净变化 Δ**。
3. **挂物理**：把每个特征翻译成**机理**，并对照判据（见下表）——**特征 → 为什么 → 意味着什么**。

## 常见判据对照（特征 → 物理）
| 图上特征 | 物理含义 / 判据 |
|---|---|
| `voidg` 升到 ≈0.99（穿越 0.99） | **烧干/CHF** 风险：局部空泡逼近 1，液膜消失 |
| 接管 `mass_flow` 出现**平台**（不再随下游压力降变化） | **临界流壅塞**：破口/喷放流量达上限 |
| 泵/环路流量**单调衰减**或**反向** | **失流 LOF**：自然循环能力不足 / 泵停 |
| 压力**单调下降** + 空泡上升 + 温度趋饱和 | **失水 LOCA**：破口泄压 |
| 稳态曲线**末端平台**（`末端趋稳≈x`） | 已达**稳态**；末值即稳态值 |
| 曲线**振荡**且持续不衰减 | 数值/流动**不稳定**，需查时间步长或两相模型 |
| 峰值**超预期范围** | 与 `set_model_intent` 的预判比对，**不一致就回头改设计**，不要圆谎 |

## 怎么讲（结论先行）
1. **一句话结论**（安/不安全、达标/不达标、趋势方向）；
2. **证据**：给出**具体数值与时刻**（如"voidg 在 t=3.2s 上穿 0.99"）；
3. **机理**：为什么会出现这个特征（能量/质量平衡、边界条件、物性）；
4. **风险/建议**：异常工况**必须点名**并给下一步（改边界/改几何/加时长/复核范围）。

## 边界与降级
- **只讲图能支撑的**：数据不足就再抽一次或再跑一工况，**不臆造**。
- 没装 matplotlib 也**完全能讲**——零依赖 Canvas 窗口 + `curve_features` 足够；PNG 只是**增强**，
  需要时在「结果图」窗口点「启用 matplotlib」自动安装（失败自动降级，不影响解读）。
- 图是**给人看的证据**；你的结论仍须与 `check_sanity`/`result_summary` 的**物理体检一致**，两者不能打架。
