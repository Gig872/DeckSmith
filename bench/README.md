# bench · 任务生成与失效分析评测台

配套论文：《LLM 自动生成 RELAP5 输入卡的失效分析与分层校验》

## 一、核心设计（为什么能"堆量"而不失控）

**手写真值卡不可扩展**（一张几百行、派生量相互耦合）。本台采用两条原则：

1. **族（family）参数化生成**
   一族 = 一个 `deck_fn(params)`。参数一变，**全部派生量随参数重算**：
   当量直径 `D=√(4A/π)`、加热周长 `πD`、每段换热面积 `πD·(L/N)`、每段功率乘子 `1/N`、
   倾角与高程等。真值卡由构造保证自洽，不是字符串替换。
2. **语义判据 = 行为等价**
   不比对卡片文本，只比对**关键标量**（最高温、最大空泡、最低压力、最大流量、质量误差）
   是否落在容差内。这样：
   - 编号/写法不同但物理对 → **不算错**（避免误判）；
   - 编号对但物理错 → **能抓出**（正是要研究的语义失效）。

> 局限（需写入论文"构念效度"）：两组不同的模型可能在关键标量上偶然一致。
> 因此对关键任务另设**结构化断言**（部件清单/连接/边界类型）作为补充。

## 二、文件

| 文件 | 作用 |
|---|---|
| `families.py` | 族定义：`deck_fn(params) → (真值卡, 自然语言需求, 关键标量)`；参数网格 |
| `gen.py` | 遍历各族网格 → `tasks.jsonl`（每行一道任务） |
| `tasks.jsonl` | 任务集：`{task_id, family, params, nl, reference, key_outputs}` |
| `validate_ref.py` | 抽验：渲染的真值卡能否真跑（防止生成器出错） |
| `traces/` | 各批次工具调用轨迹的只读副本（论文 4.3 分层核对的原始依据） |
| `archive/` | 历史批次归档（含 `20261019_model_drift/` 的 B 组复现试验） |

## 三、用法

```bash
python bench/gen.py            # 生成 tasks.jsonl
python bench/validate_ref.py   # 抽验参考卡可跑性
```

### 评测条件（`--knowledge`）

| 取值 | 含义 | 库的可见性 |
|---|---|---|
| `on` | 带库 | 参考样例 29 张 + 学习样例 19 张；运行中自存卡写题目私有目录，不回到共享库 |
| `off` | 无库（历史口径） | 三档初始皆空；运行中自存卡写私有目录，同批其他题**看不到** |
| `off-strict` | 严格空库 | 每个 worker 独立空库，**读与写同一目录**；每题清空，跨题不可见 |

`off` 与 `off-strict` 的差别只在“本题内自存卡能否被本题再次检索到”：`off` 不能，`off-strict` 能。
两者都关闭了历史上的两条泄漏（跨题自存卡、命令行越界读卡，后者由 `tools/shell.py` 拦截）。

> **与历史批次的口径差异**：2026-10-19 之前，`save_example(lib="agent")` 直接写进
> `find_example` 的读取目录，同批后续题目能检索到（论文 A 档 265/324 题、B 档 32/55 题）；
> 现在改为写题目私有目录。因此**用当前代码重跑不会复现论文数字**，两臂历史数值以
> `论文/数据/` 下的 CSV 为准。论文 B 组使用 `off` 口径。

## 四、扩展方式（这是"堆量"的旋钮）

加量只需改两处：

- **加参数维度**：在 `families.py` 的 `GEOMS_SINGLE / MDOTS / POWERS` 里加值，
  或给 `heater_pipe` 增加维度（入口温度、粗糙度、出口压力、瞬态 trip 时刻…）；
- **加族**：写一个 `deck_fn/nl_fn`，在 `FAMILIES` 登记其网格。建议按以下顺序扩：

| 族 | 种子 | 可扫参数 | 规模 |
|---|---|---|---|
| F1 单管受热稳态 | `pipe_flow_scan_heated_100kW_1MPa.i` | 几何×流量×功率×(水平/竖直) | ✅ 96（已生成） |
| F2 竖直通道烧干 | `chf_dryout_power_scan_template.i` | 功率、压力、流量 | ~50 |
| F3 临界流壅塞 | `choked_flow_backpressure_scan_template.i` | 背压、破口面积 | ~30 |
| F4 失流瞬态 | `lof_transient_pump_coastdown.i` | 泵惰转时间常数、功率 | ~30 |
| F5 小破口 LOCA | `loca_sbloca_blowdown.i` | 破口面积、位置 | ~30 |
| F6 双通道并联 | `parallel_two_channel_split_merge.i` | 流量分配、加热不对称 | ~30 |

**目标规模：300–600 道**（够核心/EI 的实验量）。

## 五、真值卡有效性过滤（重要）

并非所有参数组合都能收敛（如"低流量+高功率"会烧干、程序终止）。
流程对**参考卡**先跑一遍：`正常结束 ∧ 物理体检通过` 者计入任务集，否则丢弃并记录。
即：**任务集只包含"存在正确解"的题目**，这才公平。

## 六、批处理入口

| 脚本 | 作用 |
|---|---|
| `gen.py` / `gen_probe.py` | 生成任务集与语域探针题面 |
| `refrun.py` | 批量跑参考卡，固化关键标量作为期望值 |
| `ref_margin.py` | 提取全部参考解的 L3 判据余量（适用域审计依据） |
| `runner.py` | 逐题调用智能体 → L1–L4 判定 → JSONL；支持 `--workers`、`--tag`、`--only` |
| `metrics.py` | 由结果 JSONL 计算 `R_exec / R_phys / R_sem / Δ / FAR` |
| `rejudge.py` / `rejudge_l3.py` | 用归档卡复核历史判定 |
| `prep_rerun.py` / `restore_knowledge.py` | 评测前隔离样例库、评测后原样还原 |
