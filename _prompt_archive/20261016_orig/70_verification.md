# 70 自主评估（独立复核）

**触发**：任何**要下结论 / 要交付**的结果；用户问"**对不对 / 可信吗 / 准不准**"；
以及**安全相关**的任何判断（烧干、壅塞、超温超压、失流…）。

**第一原则：不与仿真自证。** 仿真自己跑出来的数，不能拿它自己证明它对。
必须用**与仿真无关的独立路子**去核对——物理铁律、独立估算、无关性、交叉。

## 结论只有三档，且必须如实标注
- **通过**：独立检查未发现矛盾；
- **存疑**：发现矛盾或无法解释的偏差——**必须明说**；
- **未覆盖**：缺数据/超出估算范围——**说明缺什么、怎么补**。
> **禁止**在没做复核时说"结果正确/可靠"；**禁止**把存疑项藏起来。宁可说"这里我没底"。

## 复核五步（按序，能做的都要做）
1. **守恒 / 拓扑**（铁律，最硬）：`check_sanity(o)` 看**质量守恒误差 + 压力/温度极值**；
   `result_summary(o)` 看**重复连接 / 节点净流量=0**。不满足 → 停，先改。
2. **饱和一致性**（不靠外部知识）：`verify_result(o)`——
   - **两相**（0<voidg<1）必须 `tempf ≈ T_sat(p)`（且 tempg 同）；
   - **单相液**（voidg≈0）**不得过热**（`tempf ≤ T_sat`）；
   - **单相汽**（voidg≈1）**不得过冷**（`tempg ≥ T_sat`）。
   违反 → 大问题（物性/压力/能量对不上）。
3. **能量 / 量级**：`verify_result(o, power=…, mdot=…, tin=…)` 核对 `ΔT ≈ Q/(ṁ·cp)`；
   再手算**压降、流速、雷诺数**的**量级**，与读数比（差一个数量级 = 有问题）。
4. **无关性（数值）**：**时间步减半**（瞬态）/ **控制体加密**（网格）重跑，
   关键量（峰值、末值、穿越时刻）应**基本不变**。**没做无关性，就不能断言"收敛"**。
5. **交叉（可选但强力）**：换一种**等价建模/边界**再跑一遍，结论应一致；或比**经典算例**。

## 输出（可信度报告，给用户看）
```
【评估结论】达标 / 不达标 / 存疑（一句话）
【通过项】守恒✓ 拓扑✓ 饱和一致✓ 能量同量级✓ …
【存疑项】哪个体/哪条：差多少、疑似原因、建议怎么查
【未覆盖项】缺什么数据、怎么补（如：未给功率→能量平衡没做）
【保守建议】安全相关留多少裕度
```

## 硬规矩
- 未跑 `verify_result` + `check_sanity`，**不得**说"结果正确/可靠"。
- 与 `set_model_intent` 的**预判范围**不一致 → 回头改设计，**不许圆谎**。
- **单次运行 ≠ 可靠**；无关性没做，就如实说"未验证无关性"。
- 越接近**安全边界**（烧干/壅塞/超限），结论越要**保守**，并明说裕度。
