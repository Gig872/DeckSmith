# 10 RELAP5 卡格式铁律（写卡必须遵守）

- 一张卡=一行；第一个数据域是**卡号(整数)**；注释用 `*` 独占一行；终止卡是**独占一行的 `.`**。
- 控制卡号：`100` 问题类型、`102` 单位、`201` 时间步长。部件卡号 7 位 `CCCXXNN`。
- **100 卡**：`new stdy-st`(稳态) 或 `new transnt`(瞬态)。
- **102 卡**：`si si`。
- **201 卡**：`结束时间 最小dt 最大dt 控制(dt选项,如3) 小编辑 大编辑 再启动`。
- **部件名卡 CCC0000**：`名称 类型`。

## 常用部件卡
- **时间相关控制体 tmdpvol**：`0101` 几何(面积 长度 体积 方位角 倾角 高程 粗糙度 水力直径 标志 = **9 项**)；
  `0200` 控制字码(**整数**, 3=压力+温度)；`0201` 时间 压力 温度。
- **单一控制体 snglvol**：`0101` 几何(9 项)；`0200` 控制字码(整数)**+初值写在同一卡**（不要拆 0201）。
- **单一接管 sngljun**：`0101` 来向 去向 面积 正损 反损 标志(6 项)；`0201` 控制字码 液流 汽流 界面速度(4 项)。
- **时间相关接管 tmdpjun**：`0101` 来向 去向 面积(3 项)；`0200` 控制字码(1=质量流量)；`0201` 时间 液流 汽流 界面速度(4 项)。
- **管道 pipe**：`0001` 控制体数 NV；`0101` 面积 控制体号；`0301` 长度 控制体号；`0601` 倾角；
  `0801` 粗糙度 水力直径 控制体号；`1001` 标志 控制体号；`1101` 接管标志 接管号(共 NV-1)；
  `1201` 控制字码 压力 温度 0 0 0 控制体号；`1300` 接管控制字码；`1301` 液流 汽流 界面速度 接管号。

## 连接码
- 部件**入口侧=CCC000000**，**出口侧=CCC010000**；时间相关控制体/接管的九位标识用 `CCC010000` 形式。

## 常见坑（务必避免）
- `0200` 第一词是控制字码，**必须是整数**（写 3，不是 3.0 / 0.0）。
- 控制体**倾角与高程必须一致**：水平(倾角0)则高程必须为 0。
- 接管类(sngljun/tmdpjun)**不能连接两个时间相关控制体**（至少一端是普通控制体）。
- 数据/表类卡号 NN 在 **XX01~XX99** 内，不要越界（如 037x）。
- 序列展开：数据卡末尾写"**终点号**"，表示该值覆盖到该控制体/接管。
