# 卡匠 DeckSmith 2.0 验收测试流程（后处理：M1–M6）

> 目的：把 2.0 新增的**后处理全链路**走一遍，确认「清洗 / 抽数 / 出图 / 读图 / 批量趋势」可用且稳。
> 每步都有**期望结果**，对不上就把现象填到最后一节的记录表。

---

## 准备（5 分钟）
1. 启动：源码 `python decksmith.py`，或双击 `dist\DeckSmith.exe`。
2. 顶栏 **⚙ 设置**：填 API Key → **获取模型** → 选模型 → **保存设置**。
3. 确认本机 RELAP5 可用（本程序**不含** relap5.exe / tpf* / 手册）。

---

## T0 · 离线单测（不需要 RELAP5）
```bash
cd C:\relap-5\agent-kit
python -m unittest discover -s tests -t .
```
**期望**：`Ran 68 tests ... OK`（0 失败）。

## T1 · 环境自检
顶栏 **「环境检测」**。
**期望**：**13/13** 通过；能看到「绘图增强 matplotlib（可选）」一行（未装也算通过）。

## T2 · 稳态算例 → 结果图（M1–M3）
对话输入：
> 帮我建一个水平圆管、水从一端流入的稳态模型，真跑通并给结果。

**期望**：
- agent 查手册 → 写卡 → `validate_i` → `run_relap5` → **正常结束 + 0 错误**；结果表有读数（压力/温度/流量）。
- 「视图 ▾ → **结果图窗口…**」：选变量（如 `tempf`）、部件 → **绘制** 出折线；
- 点 **导出 CSV** 得到 `workspace/exports/*.csv`。

## T3 · matplotlib 启用与降级（M5）
在结果图窗口：
- **若已装**：按钮「启用 matplotlib」置灰；点 **导出图片** → 生成 `workspace/exports/*.png`。
- **若未装**：点 **启用 matplotlib** → 弹确认框 → 确认后出现**安装进度窗**（逐行 pip 输出）；
  - 成功 → 按钮置灰，可导出 PNG；
  - 取消 / 失败 → **不卡界面**，仍能 Canvas 显示，并给出明确提示（降级成功）。

## T4 · 瞬态算例 → agent 读图讲结果（M6）
对话输入：
> 建一个带加热的竖直管瞬态模型跑 5 秒，然后把空泡份额随时间的变化**画出来讲一下**。

**期望**：
- agent 调 **`plot_series`** → **自动弹出「结果图」窗口**（已预选 `voidg`）；
- 答复满足「**结论先行**」：一句话结论 + **具体数值与时刻**（如"voidg 在 t=…s 升到 …"）+ 机理 + 风险；
- 若 `voidg` 触及 ≈1，应点到**烧干**判据；不得空口形容曲线。
- 可关掉「视图 ▾ → agent 出图时自动开窗」验证开关生效。

## T5 · 批量扫描 → 趋势图（M4）
对话输入：
> 帮我扫入口流量 5 / 10 / 15 / 20 kg/s，看出口温度怎么变。

**期望**：
- agent **先协商框架**（基准模型/扫描变量/观察量）→ **再问范围** → `batch_sim` 自动真跑并汇总；
- 生成 `workspace/batch/*_summary.csv`；
- 「视图 ▾ → **批量扫描趋势图…**」：选 汇总 / 横轴（如 流量参数列）/ 变量 → **绘制** 出趋势线；导出 CSV 成功。

## T6 · 自主评估（独立复核，M7）
在 T2 跑完的结果表里看**顶部「自主评估」**一段；或直接让 agent：
> 对这个结果做**自主评估**，把存疑项列出来。

**期望**：
- 出现 `[自主评估]` 报告：**饱和一致性**逐控制体给出 `✓ / ⚠存疑`，
  **能量平衡**在给了 `power/mdot/tin` 时给出 `ΔT 期望 vs 实测`；
- **结论分 通过/存疑/未覆盖 三档**；有矛盾时明确列出，**不拍胸口**；
- agent 口头报告里应体现"**存疑必明说**"，而不是一律说"结果正确"。

## T7 · 打包 exe（可选，发版前做）
```bash
build_exe.bat        # 基础版（零依赖）
build_exe.bat mpl    # 带 matplotlib（可导出精细 PNG）
```
**期望**：`dist\DeckSmith.exe` 双击可启动；首次运行在同目录生成 `config.json` 与 `workspace/`；环境检测通过。

## 出问题怎么反馈
1. **现象**：第几步、点了什么、**期望 vs 实际**；
2. **截图**：尤其「思考/工作窗口」里的报错行、弹窗原文；
3. 运行类问题贴 `workspace/runs/` 下对应 `.o` 的 `********` 错误行；
4. **多开窗口 / 卡死 / Python 报错栈** 这类一并截图。
> ⚠ 别贴 `config.json`（含你的 API Key）。
