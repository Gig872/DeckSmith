## 样例库分档（权威降序）

参考库按**权威**分档，避免"agent 批量产物"与"人工种子"混同：

```
human   人工基座（可信种子）   最高权重 · 只读 · 冲突以此为准
agent   agent 生成可信基座    已核验 · 冻结归档（不可同名覆盖）
learned agent 工作成果        可写（save_example 默认）
```

- 归档落地：`knowledge/reference/human/`（3 例）+ `knowledge/reference/agent/`（26 例）+
  `knowledge/reference/MANIFEST.json`（每例 sha256 + 核验记录）。
- 工具按档读写：`save_example(lib="human")` 拒绝；`lib="agent"` 冻结不可覆盖；默认写入 `learned`。
  `list/read/find` 标注来源，**同等相关时 human > agent > learned**。

## 批量 / 参数化仿真（新增能力）

交互式批量化自动建模：**先与人协商框架 → 再问参数范围 → 参数化模板 → 批量真跑 → 汇总**。

- `set_batch_plan`：记录批量框架（基准模型 / 扫描自变量 / 观察因变量 / 工况）。
- `batch_sim(template, vary)`：按 `{{参数}}` 模板做笛卡尔积，逐个渲染→真跑→**守恒校验**→
  汇总成表 + CSV；超上限（默认 20）拒绝；单工况失败不中断整批。
- `skills/50_batch.md`：把"先谈范围、不替用户拍板、每工况须物理自洽"写成流程。
- 已实测：3 工况扫出/入口压力 → 全部正常结束+0% 质量误差，汇总表 + CSV 正常。

## 指导原则（避免过度工程）

- **物理校验封顶于三道通用体检**：系统守恒 · 拓扑连接 · 节点守恒。够了，**不再往下堆补丁**。
- 更精细/更专业的判据（特殊瞬态稳定性、特定部件经验限值…）**交给 AI 按需自学**
  （`lookup_doc` / `web_search` → 想清楚 → 落到模型 → `remember`/`save_example` 沉淀），
  而不是由框架预置无穷无尽的专业补丁。
- 一句话：**框架保底线（通用硬伤），AI 学上限（专业细节）。**
