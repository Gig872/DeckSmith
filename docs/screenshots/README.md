# 截图目录

1. `main.png` —— 主界面（对话 + 已规范参数 + 用量）
2. `thinking.png` —— 思考 / 工作窗口（工具调用链 `▶/◀`）
3. `settings.png` —— ⚙ 设置（AI 接入 / 全局提示词 / 思考模式）
4. `envcheck.png` —— 环境检测（12 项 ✓/✗）

引用示例（放在 `README.md` 合适的段落）：
