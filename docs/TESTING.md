# 卡匠 DeckSmith · 测试者指南

> 面向拿到本项目的**组员 / 朋友**：怎么装、怎么配、怎么用、怎么反馈。
>
> **2.0 后处理专项验收**见 [`TEST_PLAN_2.0.md`](TEST_PLAN_2.0.md)（T0–T6 逐步验收 + 结果记录表）。

## 0. 你需要准备
- **Windows x64**（有桌面）；Linux 理论上也能跑源码，但 exe 只做了 Windows。
- **RELAP5**：本程序**不包含**它。你需要本机装有 `relap5.exe` 及其物性文件 `tpf*`（同一目录）。
- **大模型 API Key**：DeepSeek / OpenAI / 通义 / 智谱 / Moonshot，或本地 Ollama——任一 OpenAI 兼容端点。

## 1. 启动（两种方式，二选一）
- **A. 单文件 exe**：双击 `DeckSmith.exe`（无需装 Python）。
- **B. 源码**：装 Python ≥ 3.9（含 tkinter），在项目目录执行 `python decksmith.py`。

## 2. 首次配置（重要）
点顶栏 **⚙ 设置**，依次填：
1. **供应商**（下拉，自动填 `base_url`；也可手动改成本地/自建端点）；
2. **API Key**：填你自己的；
3. 点 **「获取模型」** → 从接口拉取可用模型，在**模型**下拉里选（也可手输）；
4. 可选：填**全局提示词**（附加到系统提示）；
5. 点 **「保存设置」**（写入 exe/源码同目录的 `config.json`）。

> `RELAP5 目录`：程序会**自动探测**；探测不到就在 `config.json` 的 `relap5_dir` 填，或设环境变量 `RELAP5_DIR`。
> `手册`：`lookup_doc` 需要一份输入卡手册 `.md`（**不随程序分发**）。在 `config.json` 的 `doc_path` 填路径，或设 `RELAP5_DOC`。

## 3. 先自检
点顶栏 **「环境检测」**，确认 12 项里跟"能不能跑"相关的都 ✓（Python / tkinter / 依赖 / config / API Key / 模型 / RELAP5 可执行 / 物性 tpf* / 手册 / 技能 / 样例库 / 工作目录可写）。

## 4. 怎么用（示例）
- **建模型**：「帮我建一个水平圆管、水从一端流入的稳态模型。」
- **答疑**：直接问「什么是水力直径？」——它会像正常助手一样解释。
- **看它在想啥**：**视图 ▾ → 思考/工作窗口**，实时看它查手册、写卡、真跑、校验。
- **批量**：「帮我扫入口流量 5/10/15/20 kg/s 看出口温度」——它会先跟你协商框架、再问范围、再自动跑一批。
- **多会话 / 停止 / 术语速查 / 导出**：见顶栏。

## 5. 已知限制
- 仅 Windows gui；单轮有 **token/步数上限**（超复杂目标需**分批**）。
- 复杂部件（透平、点堆等）自举仍在完善；物理校验聚焦**通用硬伤**（守恒/量级/拓扑），更专业判据由模型按需自学。
- 开了**思考模式**会更慢更贵，且仅对支持的模型生效。

## 6. 出了问题怎么反馈
把下面几样发给我：
1. **现象**：哪一步、点了什么、期望 vs 实际；
2. **截图**（尤其"思考/工作窗口"里的报错行）；
3. 若是运行问题，贴 `workspace/runs/` 下对应 `.o` 里的 `********` 错误行。
> ⚠ 别贴 `config.json`（里面有你的 API Key）。

## 7. 目录速览
```
DeckSmith.exe        程序
config.json          你的设置（含 Key，勿外传）
workspace/           工作区：runs/（RELAP5 输出，自动只留最近若干次）、sessions/（会话）、batch/、notes/
knowledge/           learned/（它学到的样例）；参考库随程序打包在内部
```
